# Eat the World

A private, friends-only game: eat at a restaurant that specialises in each country's cuisine, collect passport stamps, and plan the next dinner together. It starts in London.

- `eat-the-world-london-brief.md`: the build brief. Hand it to a Claude Code session to build the MVP.
- `seed/`: the fact-checked London restaurants, sets, signature dishes and the ISO country list (CC BY-SA 4.0; see its licence file).
- `docs/fact-check-2026-10-05.md`: evidence and sources for every seed row and every technical claim in the brief, plus leads for new restaurants.
